# IRLIX Sales Hub 4.0 — integration
Route /projects/sales-hub. Existing Project 73 login. Admins always have access; other users only if granted in Access. Import and export are admin-only. All tables have saleshub_ prefix, no existing data replaced. User removal preserves contacts and history (nullable owner and actor).
Import: download Google Sheet as XLSX, upload through Import, review counts, re-upload same file via confirm. SHA-256 binds preview to the exact workbook for 15 minutes. Initial import preserves all rows including duplicates; append imports skip exact identities and potential overlaps, never overwrite working fields. Original row values, source columns and company discrepancy remain in raw JSON. Unmapped owners retain source text; exact eligible username can be mapped. No original workbook is written to persistent storage; PHP upload temp file is used. No real contacts in repository, CI, or logs. Do not include PII in issue reports.
The current source uses tabs Контакты (headers row 1) and Справочник холдингов (headers row 3). The other tabs are derived views and are not imported. Formula cells are read only as cached values, never executed. Import preview counts must be reconciled against fresh export. Expected baseline 6124 contacts, 3395 named companies; counts may differ after source edits. Preserve Google Sheet unchanged until acceptance. Repeated imports skip possible matches for manual review; no automated merging.
Production uses existing CI/deploy with SQLite backups. Before importing real data confirm approved hosting/access/retention. No service worker offline cache for this route. Browser/real workbook validation and authenticated production checks are required before team rollout.

Sales Hub HTTPS location uses a bounded 16 MiB request body, PHP upload limit 15 MiB, and 120s FastCGI timeout; access logging is disabled for this location to avoid recording search terms. Existing routes keep their former limits. Deployment performs nginx -t before reload.

Quick assignment from the list/card: any authorized manager can assign a free contact to self or another eligible employee. Admin alone can reassign/release existing ownership. Assignment uses the row version and SQLite transaction, preserves working fields, and changes a New contact to In work when assigned. CSV export is admin-only at both UI and controller/route. Channel buttons show present/missing separately, reveal all semicolon-separated values, allow copying each or all, and retain safe mail/tel/HTTPS actions. Clipboard writes happen only on user click.
