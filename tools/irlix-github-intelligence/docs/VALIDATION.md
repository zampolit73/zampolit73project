# Проверка версии 1.0.0

Дата для пользователя: 26.10.2026, Europe/Astrakhan. В базе и отчётах время сохранено в UTC; поэтому тестовые записи имеют календарную дату 25.10.2026 UTC.

## Выполнено

- 48 автоматических тестов unittest: успешно, Python 3.12.14, Linux.
- Разбор демонстрационных TXT и CSV: 3 файла, 4 синтетические находки; отдельная тестовая база.
- Реальное обращение к GitHub REST: метаданные публичного репозитория, /rate_limit, поиск репозиториев, commits, trees и blobs.
- Реальный поиск «аутстафф in:name,description,readme is:public»: найдено и записано в очередь 26 репозиториев. В бюджет этого отдельного smoke-теста вошло чтение одного файла одного репозитория. Остальные кандидаты не считаются прочитанными.
- Финальный целевой smoke-тест: 2 публичных репозитория, 10 запросов API, прочитаны 4 файла, получены 5 сигналов. Для теста сознательно установлен лимит 3 файла на репозиторий; ещё 13 файлов остались pending. Это не полный обход двух репозиториев.
- Из этих 5 сигналов два имеют класс B: публичные записи опыта Xsolla и VK с isOutstaff: true. В тексте указаны исторические периоды 2020 и 2020–2022. Они не объявляются подтверждёнными контрактами или спросом 2026 года.
- XLSX финального smoke-теста: 5 строк находок, 31 столбец, 5 вкладок, числовые приоритеты, фильтр, закрепление заголовка, 5 ссылок на источники, нет активных формул из входных данных. Значения сверены с JSON.
- Синтетические проверки включают salary ≠ rate, неизвестную валюту/единицы, НДС, роли на соседних строках, отдельные записи JSON/CSV/XLSX, многосторонние фрагменты, анонимизацию, отрицания, HTML/formula injection, чтение DOCX и пустого PDF, private repo rejection, HTTP 429, бюджет, incomplete_results, разбиение насыщенного поиска и возобновление после прерывания.

Результат целевого smoke-теста включён в examples/live_run_2026-10-26. Это пример формы результата, а не новый полный рыночный обзор. Другие найденные источники из прежнего ручного исследования не считаются прочитанными этим парсером.

## Что не проверено вживую

- Аутентифицированный глобальный поиск по коду: в среде не было GITHUB_TOKEN. Его обработка проверена тестами и по текущей документации GitHub; у пользователя нужна команда doctor --check-code-search.
- Выполнение установочного PowerShell-скрипта на Windows. Скрипт предназначен для Python 3.10+; runtime здесь Linux.
- Нагрузочный проход по десяткам тысяч репозиториев; полнота/precision/recall не измерены на размеченной выборке.
- Визуальный рендер HTML в Chromium: бинарник браузера отсутствует в среде. Структура HTML и экранирование проверены тестами; это не проверка вида во всех браузерах.
- Нативное открытие в Microsoft Excel. Структура, типы и гиперссылки проверены программно.

Развёртывание на VPS, интеграция с сайтом и запуск по расписанию не выполнялись. Архив содержит исходники, конфигурацию, инструкции, тесты и пример результатов; GitHub token отсутствует.
